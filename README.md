# Web Launcher Plugin

> 基于 ZTools 插件系统的快速启动工具，支持网页快捷访问与多标签分类管理

# 📖 项目介绍

Web Launcher 是一款专为 ZTools 设计的插件，帮助你快速启动网页和搜索引擎。通过标签分类管理，你可以将常用的网站、搜索入口有序组织，并通过 ZTools 主界面快速调用。

本项目基于 `ZToolsCenter` 插件仓库开发，灵感来源于原 [web-quick-open](https://github.com/ZToolsCenter/ZTools-plugins/tree/main/plugins/web-quick-open) 插件，但在功能与交互上进行了全面重构与增强。

# ✨ 功能特性

## 🚀 核心功能

- 快捷启动：通过 `ZTools` 主界面输入名称，快速打开网页或搜索引擎
- 搜索模板：支持 `{q}` 占位符，输入关键词即可跳转搜索
- 多标签分类：为每个网页/搜索引擎添加多个标签，实现灵活分类
- 类型筛选：支持按「`全部` / `网页` / `搜索`」快速过滤

## 🏷️ 标签管理

- 自定义标签：自由创建、编辑、删除标签，支持自定义颜色
- 单选标签筛选：点击标签即可筛选对应分类的条目
- 未分类条目：快速定位尚未打标签的条目

## 📋 条目管理

- 添加 / 编辑 / 删除：完整的 CRUD 操作
- 启用 / 禁用：临时隐藏不需要的条目
- 图标自动获取：输入 URL 即可自动获取网站 Favicon
- 去重校验：防止添加同名同类型的重复条目

## 🎨 视图切换

- 网格视图：卡片式展示，适合浏览
- 列表视图：紧凑型展示，适合管理

## 🔍 搜索与筛选

- 全局搜索：支持按名称、URL、标签名搜索
- 类型筛选：快速切换显示网页或搜索引擎
- 标签筛选：点击标签筛选对应分类
